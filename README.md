# Penukula Mahesh Kumar - Portfolio

A responsive GitHub Pages portfolio based on the visual structure of the reference portfolio:
https://saitejhub.github.io/sai-teja-portfolio/

## Files

- `index.html` - portfolio content and structure
- `style.css` - responsive dark portfolio design
- `script.js` - mobile navigation, reveal animations and current year

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `mahesh-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. GitHub will provide the live portfolio URL.
